# IMPORTANT — read before pip-installing:
#
#   This file pins ALL versions to match what uv.lock resolved.
#   Mixing versions (e.g., using the old transformers==4.46.3 that
#   Cell 1 used to install) will break import-time compatibility.
#
#   The two most common mistakes people hit:
#     1. transformers 4.x installed → conflicts with trl 0.24.0 API
#     2. torch 2.5.x or 2.6.x on Windows → no torchao wheel exists yet
#     3. pip not installed in venv → all installs fail
#
#   Safe install command (run once, then restart your kernel/runtime):
#
#   Windows (cmd):
#     python -m ensurepip --upgrade
#     python -m pip install --upgrade pip setuptools wheel
#     python -m pip install -r requirements.txt --index-url https://download.pytorch.org/whl/cu124 --extra-index-url https://pypi.org/simple
#
#   Linux/Mac (bash):
#     python -m ensurepip --upgrade
#     python -m pip install --upgrade pip setuptools wheel
#     pip install -r requirements.txt --index-url https://download.pytorch.org/whl/cu124 --extra-index-url https://pypi.org/simple
#
